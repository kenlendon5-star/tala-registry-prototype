# D03 — Native app shell

Implemented 2 October 2026. Repository card: **Verify**. Day 3 implementation and device acceptance are recorded here; D01/D02 scope/setup sign-off is not inferred from these tests. Existing browser-local board progress is preserved.

## Delivered

- Native Material 3 Home, searchable/filterable household list, and interview overview/member/section previews.
- Tala light/dark colors, responsive scrolling, system-bar insets, keyboard resize and Android Back navigation.
- `HouseholdId` and `MemberId` types; a navigation argument adapter serializes household identity into the saved back stack.
- Separate registry/interview ViewModels with immutable UI snapshots, lifecycle-aware StateFlow collection, saved search/filter/tab state, and an observable household repository interface.
- Explicit fictional sample repository. Missing records have an unavailable state; member identity does not depend on list order.
- Standard Gradle wrapper and [native setup guide](../../android-native/README.md).
