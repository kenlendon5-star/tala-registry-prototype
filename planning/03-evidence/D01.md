# D01 — Agree on the release

Recorded as complete on 8 October 2026. The agreement itself was produced during planning; this record lists the artifacts that hold it.

## Delivered

- **Scope.** [30-day plan](../01-boards/ANDROID-30-DAY-PLAN.md) fixes the deliverable as an offline Kotlin + Jetpack Compose rewrite: all 18 questionnaire sections, household/member editing, callbacks, signatures, photos and counts, branching/validation, save/resume, native GPS and manual coordinates, online map with offline fallback, Room storage, versioned JSON export/restore, reversible archiving, device testing, a signed APK, documentation and defence material. Production login, server-enforced access, encrypted storage, cloud sync, supervisor portal and Play Store launch are explicitly a later phase.
- **Capacity and schedule.** One developer, 164 focused hours over 30 consecutive calendar days, four sprint gates, and the daily 6-hour cadence with a single Work-in-progress card building and one verifying.
- **Environment.** Native build in `android-native/`, Android Studio, target phone OPPO CPH2529 / Android 15, minimum SDK 26, offline-first with no laptop or server at runtime; the browser prototype and Expo starter stay as behaviour references only.
- **Acceptance.** Each card carries a testable "Done when" line and a named deliverable, and the plan ends with a release acceptance checklist (install/upgrade, offline interview, force-stop/reboot survival, failure reporting, migrations, backup/restore, UAT, version/hash, guides).
- **Risk rules.** Pre-agreed responses for a failed foundation slice, newly mandatory backend work, unavailable questionnaire wording, schedule slip, missing reviewer and a Day 29 release blocker.
