## Reproduce

From `android-native/`:

```powershell
rtk proxy ./gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest -PisolatedTestApp=true
```

Then from the root, with the selected device unlocked:

```powershell
rtk proxy powershell -NoProfile -File tools/verify-d12-device.ps1 -DeviceSerial emulator-5554
rtk proxy node tools/port-native-questionnaire.cjs --check
rtk proxy node planning/02-progress/verify-board.cjs
rtk proxy node tools/check-docs.cjs
```

Use `-DeviceSerial e7d5dc18` when the OPPO target is connected. The normal application package and its saved data are preserved. Build without `-PisolatedTestApp=true` for the normal APK.

## Limits and next gate

The restoration test destroys/recreates the ViewModel after an Android Bundle/Parcel round trip. It does not simulate an actual OS process kill while typing. Separate UI scenarios do force-stop and verify confirmed saved answers. Full low-storage/process-death/accessibility/performance acceptance remains D20/D22.

Evacuation-site labels remain visibly marked `(Sample)`; official locality/program decisions still require approval before real use. D13 interview lifecycle/signature acceptance and D14 peer review remain separate work packages. No export/restore, GPS/map, signed-release or field-pilot readiness is claimed here.
