## Delivered behavior

- Registration uses `QuestionnaireSections`, shared native controls and scoped Room draft saves. Names derive from structured answers; legacy names remain intact until components are entered. Separate editors direct structured-name changes through Name details and keep household addresses synchronized.
- Enumerator name, barangay and picture persist in DataStore. New households capture an attribution snapshot at creation; changing the current profile does not silently restamp existing records.
- Both picture slots launch Android Photo Picker and preview saved copies. Input is bounded to 5 MiB, validated as JPEG/PNG/WebP, processed on the IO dispatcher and normalized to JPEG with at most a 1600 px longest side and 1 MiB output. Invalid, unavailable, oversized and unwritable images report failure.
- Replacement commits the durable reference before deleting the old copy. Failed persistence keeps the old reference/file and cleans the staged copy. Startup recovery removes unreferenced UUID-named copies. Media tests use dedicated temporary directories.
- Text input no longer waits for a database read on every keystroke. Questionnaire answers entered during draft or photo writes remain in the draft and are saved afterward. Failed photo operations can be retried; saved acknowledgements clear when drafts change.
- Active counts exclude archived households and distinguish Male, Female and unrecorded sex. Member editing/removal and archive/restore update the live summary.

## Reproduce

From `android-native`:

```powershell
rtk proxy ./gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest -PisolatedTestApp=true --console=plain
rtk proxy ./gradlew.bat :app:lintDebug -PisolatedTestApp=true --console=plain
```

From repository root, with the authorized target phone connected and unlocked:

```powershell
rtk proxy powershell -NoProfile -File tools/verify-d08-device.ps1
rtk proxy node planning/02-progress/build-board.cjs
rtk proxy node planning/02-progress/verify-board.cjs
rtk proxy node tools/check-docs.cjs
```

The runner verifies the isolated application ID before installation, stops on failed suites, and runs fixture write/read in separate processes with force-stop between them. Build without `-PisolatedTestApp=true` to produce the normal `ph.tala.registry` debug APK.
