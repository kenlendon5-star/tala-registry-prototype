# D18 — Restore and migrate safely

Implemented and verified on 24 October 2026 on the Android 17 / API 37 emulator using the isolated `ph.tala.registry.d08test` debug application. All test records and attachments are fictional.

## Delivered

- Reports opens a versioned Tala JSON backup through Android's Storage Access Framework, validates it before writing, and shows household, attachment, and matching-ID replacement counts before confirmation.
- Import enforces the 50 MiB file cap, supported format and questionnaire version, UUID/reference/scope invariants, display-code ownership, strict dates, bounded answers, and attachment size, SHA-256, MIME type, and decoded image format.
- Attachments stage in app-private storage before one Room transaction replaces the selected complete graphs. A failed transaction removes staged files and preserves prior records; cleanup failure after commit cannot remove newly referenced media.
- Hidden dependent answers are cleared with the native questionnaire rules. An imported `Reviewed` record that fails current review rules is restored as `InProgress` rather than receiving a false completion state.
- Room schema version 5 adds the durable cloud outbox and acknowledged owner/household sync revisions through the non-destructive `MIGRATION_4_5` migration.
